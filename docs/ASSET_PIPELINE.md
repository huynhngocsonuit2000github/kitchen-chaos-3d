# Asset production pipeline — no paid services by default
Use Blender (model, UV, rig, animation, bake, glTF), Krita/GIMP (texture painting), Inkscape (SVG), Audacity (record/edit), optionally LMMS (original music), FFmpeg (audio encoding), glTF Validator and glTF Transform (inspect/optimize). Check installed tools/versions and actual availability in Codex before committing to commands. Blender can run headless if installed; if not, request approved environment or hand off exact .blend work; do not claim output. No external AI generation dependency for runtime. Generated reference PNGs are concept-only.

## Source candidates and rights
Blender GPL tool does not automatically impose GPL on original output (https://www.blender.org/about/license/ and https://www.blender.org/support/faq/). Poly Haven CC0 textures/HDRI (https://polyhaven.com/license); use only a stylized compatible texture and record exact asset URL. Kenney https://kenney.nl/assets and Quaternius https://quaternius.com/ are candidates for support props/rigs; verify each pack license and visual fit before import. Freesound https://freesound.org/ and OpenGameArt https://opengameart.org/ have mixed licenses: prefer CC0; CC BY only with recorded attribution; no NC/ND or unclear redistribution, no ripped games. Font candidate https://fonts.google.com/ (verify individual OFL/license); system fallback until then. No downloaded third-party file or individual license validated in this pack. All sources require actual file, license evidence, creator, exact URL, date, modifications, redistribution rights and checksum in ledger before shipping. Public repository and web delivery both count as redistribution.

## Recipe for each production batch
1. Read concept and scale budgets; choose original procedural or manually refined model. Save repeatable script/seed and .blend under assets/source/ (not public runtime). Block if necessary tools unavailable, continue independent tasks. Create rounded bevels, weighted normals, material swatches and UVs; no raw cubes as final. Hero chef/food require manual visual iteration even when procedural.
2. For modular props build parametric grid footprints, rounded cabinet panels, handles, buttons, hinges, feet; use shared material atlas. UV unwrap and pack, bake AO/color if useful, use simple roughness; 512–1024 texture, no baked lighting conflict. Export GLB with transforms applied, root at base, meter units, +Y up glTF, sockets named by manifest, collision proxies separate. Keep textures power-of-two, avoid unnecessary alpha.
3. Rig base chef with shared bones, skin/weight paint, deform test shoulder/elbow/knee. Author reusable named keyframes using Blender actions/NLA, export clips, verify actual imported names/durations and sockets. Retarget any licensed source animation, check foot sliding and contact; no automatic quality claim.
4. Food: build rounded procedural meshes with layered material variants, shape distinct raw/cooked states, stack sockets and plate attachment. Render at actual camera scale; use silhouette/color/texture not just recolor. Icons rendered from final GLBs on neutral background or original SVG, not cropped concept board.
5. VFX: original SVG/painted particle textures, procedural emitter curves, pooled billboards, capped counts, no simulation-heavy fluid. Audio: record foley locally or generate original synth/noise cues; trim/DC-remove/fade/normalize in Audacity, export OGG with WAV source. Compose original short music loop in LMMS or license exact track. Target no clipping, loop seams inaudible; priority warnings over ambience; audio unlock on user gesture. No copyrighted samples.
6. Export to assets/runtime/<group>/; validate GLB with glTF Validator, inspect bounds/materials/tris/texture bytes/clip names and runtime screenshot, measure actual file sizes. Optimize via glTF Transform only after baseline comparison; texture compression KTX2 and mesh compression if decoder configured and tested. Use manifest path, checksum and license status; actual file required for generated/imported, engine evidence for verified. Never mark missing as done. Source assets excluded from Vite public copy; runtime only imported/lazy-loaded as needed.

## Tool commands (templates, NOT_RUN)
`blender -b --python tools/art/build_<batch>.py -- --out assets/runtime` (author scripts in M2, check Blender version first); `npx @gltf-transform/cli inspect <file.glb>` (pin reviewed version in tooling); `ffmpeg -i input.wav -c:a libvorbis -q:a 5 output.ogg`. Validate before/after optimization and check dependencies are free and usable. Runtime batch output acceptance is per asset in production/ASSET_MANIFEST.csv. Do not substitute downloaded random assets for approved style.
